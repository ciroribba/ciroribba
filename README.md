# ¡Hola! Soy Ingeniero Frontend & Data Science 🚀

Ingeniero Frontend con sólida experiencia en React, Next.js, Angular y ecosistemas modernos de JavaScript. 

He liderado desarrollos técnicos para productos financieros y plataformas web de alto tráfico, definiendo arquitecturas escalables, flujos UI/UX y estrategias de integración con APIs REST.

Mi objetivo es combinar excelencia técnica, diseño centrado en el usuario y análisis de datos para construir soluciones que generen impacto real en el negocio.

En paralelo, me especializo en Ciencia de Datos, fortaleciendo la toma de decisiones basada en métricas y optimización continua de producto.

Me apasiona el aprendizaje constante, el trabajo en equipo y la búsqueda de calidad en cada detalle.

## 🛠️ Tecnologías y Stack Tecnológico

- **Frontend & Core:** 
  - Lenguajes: TypeScript, JavaScript, Python (Librerías de Python y Machine Learning), HTML5, CSS3
  - Frameworks / Librerías: React, Next.js, Angular
- **Backend & Bases de Datos:** Node.js, Express, PostgreSQL
- **Seguridad & Testing:** BurpSuite
